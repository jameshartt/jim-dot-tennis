Where to find the club name and id

BHPLTA does not publish them; they appear only after signing in with your club code. Once the club code is saved, the “Look up from BHPLTA” button below fetches them for you. To find them by hand:

  1. Open the BHPLTA “Parks League Match Cards” page in a desktop browser and enter your club code.
  2. Open the browser's developer tools and inspect the page heading (your club's name): it carries data-clubid and data-clubname.
  3. Alternatively, change the week selector with the developer tools' network tab open: the request to admin-ajax.php sends club_id and club_name.
