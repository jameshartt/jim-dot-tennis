The app printed a one-time code in its server log when it started, in a box headed "SETUP CODE". Copy it here. Capitals, spaces and dashes don't matter.

Where do I find the server log?

Whoever installed the app can see its log. With Docker, run docker compose logs app in the folder the app was installed from.

Restarting the app prints a fresh code and cancels the old one.

Why is there a code?

The code proves you are the person running this app. Without it, anyone who found the web address first could make themselves its administrator.
